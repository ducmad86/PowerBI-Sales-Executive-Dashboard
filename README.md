# Executive Sales & Profit Dashboard

## 📌 Business Overview
Báo cáo quản trị phân tích tình hình kinh doanh, doanh thu và lợi nhuận nhằm hỗ trợ Ban điều hành đưa ra các quyết định chiến lược về thị trường và dòng sản phẩm.

## 📊 Key Insights
- **Sản phẩm chủ lực:** Dòng sản phẩm **Paseo** đóng góp doanh thu cao nhất (đạt trên $30M).
- **Thị trường trọng điểm:** **Mỹ (USA)** là thị trường mang lại doanh thu lớn nhất.
- **Phân khúc khách hàng:** Phân khúc **Government (Chính phủ)** chiếm tỷ trọng lợi nhuận áp đảo (trên 65%).
